# Pointage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App Next.js sur Vercel : pointage via Raccourci iOS, tableau mensuel et plan de rattrapage des heures manquantes.

**Architecture:** Next.js App Router. Calcul pur dans `lib/calc.ts` (testé), stockage Upstash Redis dans `lib/store.ts`, routes API protégées par `PUNCH_TOKEN`, une page client mobile.

**Tech Stack:** Next.js 15, TypeScript, @upstash/redis, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-18-pointage-design.md`

## Global Constraints
- Fuseau : Europe/Paris pour tout découpage en jours et affichage.
- Interface en français, mobile d'abord.
- Variables d'env : `PUNCH_TOKEN`, `KV_REST_API_URL`, `KV_REST_API_TOKEN` (noms posés par l'intégration Upstash de Vercel).
- Réglages par défaut : `hourlyRate: 12.31` (SMIC brut au 1er juin 2026), `hoursPerDay: 8`, `workDays: [1,2,3]` (lun–mer), `dayEnd: "18:00"`.
- Retenue = ceil(manque en minutes / 60) × taux.

## Review Focus
- Double appui accidentel (< 60 s du précédent) → ignoré, réponse « Ignoré (doublon) ».
- Sortie oubliée un jour passé → segment ouvert compté 0, jour signalé `missingExit`.
- Pointage en cours aujourd'hui → compté jusqu'à `now`.
- Fin de mois sans jour restant → plan vide, retenue finale affichée.
- Changement d'heure (DST, fin octobre/mars) → jours découpés en heure de Paris, pas en UTC.

### Task 1: Scaffold + calcul

**Files:**

- Create: `lib/time.ts`, `lib/calc.ts`, `lib/types.ts`
- Test: `lib/calc.test.ts`

**Interfaces:**
- Produces:
  - `type Settings = { hourlyRate: number; hoursPerDay: number; workDays: number[]; dayEnd: string }`
  - `DEFAULT_SETTINGS: Settings`
  - `parisDay(ms: number): string` → `"YYYY-MM-DD"`; `parisHM(ms): string` → `"HH:MM"`
  - `computeMonth(punches: number[], settings: Settings, now: number): MonthReport`
  - `MonthReport = { month: string; days: DayRow[]; pastBalanceMin: number; deficitMin: number; retainedHours: number; retainedEuros: number; plan: PlanRow[]; dueMonthMin: number; workedMonthMin: number }`
  - `DayRow = { date: string; dueMin: number; workedMin: number; balanceMin: number; punches: number[]; missingExit: boolean; isToday: boolean }`
  - `PlanRow = { date: string; targetMin: number; extraMin: number; suggestedEnd: string }`

Règles (algorithme) :
- Jours du mois de `now` (Paris). `dueMin` = hoursPerDay×60 si jour de semaine ∈ workDays.
- Pointages d'un jour triés, pris par paires. Impair : si aujourd'hui, dernier segment compté jusqu'à `now` ; sinon `missingExit = true`, segment ignoré.
- `pastBalanceMin` = Σ (worked − due) des jours < aujourd'hui (jours non travaillés inclus).
- `deficitMin` = max(0, −pastBalanceMin).
- Jours restants = jours travaillés ≥ aujourd'hui. `extraMin` = ceil(deficitMin / nbRestants). `targetMin` = due + extra. `suggestedEnd` = dayEnd + extra.
- `retainedHours` = ceil(deficitMin/60) ; `retainedEuros` = retainedHours × hourlyRate (arrondi au centime).
